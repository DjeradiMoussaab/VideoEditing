# Corporate Trend presentation openers

The eleven layouts are recreated from the user-supplied Corporate Trend preview and inspected After Effects project. SVG/FFmpeg reproduces the layout, rounded diagonal media windows, decorative tiles, title entrances and transitions; this is not a native After Effects render or a verified pixel-identical conversion of its effects/keyframes.

The placeholder image is from the supplied `(Footage)/Image 1.jpg`. Selected images or video replace it; multi-window designs use the scene's selected media in each window, cropped separately.

Raleway matches the source's Font link.txt. Static Black (900) and Bold (700) faces were generated from https://github.com/google/fonts/tree/main/ofl/raleway and renamed internally to Presentation Black/Bold for deterministic selection. See OFL.txt. Shared glyph advance metrics support bounded text wrapping. No After Effects installation is required at runtime.
