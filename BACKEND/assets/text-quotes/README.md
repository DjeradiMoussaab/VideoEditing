# Text Quotes

The six user-selected layouts were reconstructed from the supplied `text-quotes-mogrt-SBV-347263808` pack and its 3840×2160 preview:

| Style | Source template |
| --- | --- |
| Framed | Text Quotes 07 |
| Wide | Text Quotes 04 |
| Editorial | Text Quotes 06 |
| Oversized | Text Quotes 08 |
| Stacked | Text Quotes 01 |
| Right aligned | Text Quotes 03 |

`SHARED/text-quotes.mjs` defines the editable layout, source colors, chevron proportions and smooth masked entrances/exits. Timing is reconstructed from the preview; this is not execution of the original After Effects project. Explicit newlines preserve line placement; longer text is fitted to the design. Preview and export use the same composition. The reading hold expands for longer scenes and short scenes compress animation timing.

The bundled Black Han Sans Regular is the font listed by the original MOGRT project report. It comes from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/blackhansans) under the included SIL Open Font License. `SHARED/black-han-metrics.mjs` contains normalized advance widths from this font. Source preview logos, stock footage and demo branding are not part of the templates.
