# Typography quote styles

Based on the user-supplied `typography-text-titles-20-mogrt-SBV-348859936`.
`template-01.json` and `template-02.json` are the original MOGRT definitions.
Both specify Montserrat-Black (despite the generic help file listing other fonts),
uppercase text, highlight word indices, colors and layout positions.
The bundled font comes from the Montserrat author's repository with the OFL license.

The source MOGRTs contain an After Effects project and no footage. Default images
are cropped from clean opening frames of the supplied previews, excluding demo
branding. Selected scene images or videos replace them. Focus uses a full-screen
blurred monochrome image; Split keeps the image on the right with a monochrome filter.

Shared word layout drives SVG cards and FFmpeg export, with measured font advances,
word-boundary wrapping, editable highlights, sequential entrance, and a gentle
background drift during the hold. Default images are stills; they are not the
original demo videos. Adobe's text animator is reconstructed, not executed or
certified pixel-identical. No music, branding or audio track is included.
